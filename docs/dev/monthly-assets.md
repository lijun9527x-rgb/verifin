# 月度资产与统一支出账户

## 账户组织

- `Account` 是余额记录单位，一条记录对应可以独立核对余额的资金账户。
- `AccountGroup` 表示所属银行卡或平台，同一卡下可建立活期、定期、基金等多个账户。分组本身不再重复记一份余额。
- `Account.type` 继续表示卡号、信用额度等能力；新增 `Account.assetClass` 表示资产性质：活期、定期、债券基金、股票类基金、外币定期、外币活期、其他资产。
- 旧账户与旧备份没有 `assetClass` 时回落「其他资产」，由用户在账户详情中分类，不根据名称猜测。
- 多笔到期日不同的定期可以分别建账户。资金从活期转入定期或基金仍记转账，不计为生活支出。

## 月度资产

入口：资产页 → 月度资产对照。

- 窄屏表格展示所选月与上月，宽屏增加更早一月，差额可横向查看；支持按资产类别、银行卡或账户查看，账户视图可显示原币。
- 当前月尚未保存时展示草稿，历史月没有快照时显示缺失，不推测历史估值。
- 「核对余额」预填账户流水推导的余额，可按账户填写原币余额或基金市值；外币账户逐个直接填写对应人民币金额，不输入汇率，再显式保存。
- 保存仅写月度资产快照，不改写账户余额、不生成收入或支出。快照与日常流水是两套用途不同的记录。
- SQLite v20 新增 `asset_month_snapshots`（`id/book_id/payload`），每账本每月一条记录。`payload` 保存强类型 `AssetMonthSnapshot` 的 JSON，包含核对时间、本位币、账户标识、名称、银行卡分组标识与名称、资产类别、原币余额及手动填写的本位币估值；旧快照汇率字段仍可读取。
- 银行卡按稳定分组标识跨月对照，改名不产生虚假的资金转移；显示名称取所展示月份中最新的快照名称。
- 历史月份不会随账户改名、分类调整或当前估值更新而改变。覆盖已保存月份前必须确认，其他月份不变。
- 汇总逐月使用该月冻结的类别与银行卡信息；一个账户不重复计入不同分类。原币金额只用于账户视图，同币种以外的汇总统一使用本位币。
- 任一非零外币余额未填写人民币估值时，该月相关汇总及变化值不展示不完整金额。零余额未填写估值时按零处理。
- 只有两个月数据都完整时才展示差额。缺快照显示「—」；已有完整快照但不包含某账户/类别时，其金额为零。
- 删除账户后保留已保存的历史快照及名称，删除账本时清除该账本快照，重置全部数据时清空所有快照。

## 统一支出账户

- 设置 → 记账 → 统一支出账户，复用原 `defaultAccountIds` 按账本保存指定账户。
- 新支出在 Controller 写入前统一路由：手动、AI 确认、账单导入确认、周期补记使用同一规则。未指定账户时维持原有逐笔选择行为。
- 新支出编辑器显示实际指定账户，分类历史习惯不能覆盖它。导入预览明确提示最终扣款规则。
- 账户币种不同于交易币种时，保留交易原币与冻结本位币金额，仅换算扣款账户实际金额；人民币本位币账户直接使用冻结本位币金额。
- 指定账户不可用或换算缺率时拒绝写入，不能静默扣另一账户。
- 历史交易编辑、收入、转账、退款和系统余额调整保留各自账户，更换指定账户不迁移历史支出。

## 首页分类预算

- 首页 `budget` 面板改为 `HomeCategoryBudgetPanel`，展示已设置预算的分类，不再展示总预算圆环。
- 点击首页分类行直接编辑该分类本期额度；标题或月份入口进入预算总览。预算设置页仍管理每期沿用的默认额度。
- 各分类显示预算、已支出、剩余与进度；零支出分类仍显示。父分类预算包含子分类支出，不对父子预算再次求和。
- 默认预算和单月覆盖的优先级、预算周期及「不计入预算」规则不变。总预算仍在预算总览和设置中管理。

## 备份与校验

- `assetSnapshots` 和账户 `assetClass` 随现有 JSON/压缩/加密备份导出恢复；旧备份没有快照字段时按空列表恢复。
- 导入前检查所属账本、本位币、账户标识唯一性、币种和金额精度；手填外币估值作为独立金额保存，不根据汇率校验或反推。
- 仓储整表保存契约、整账本原子替换、写入失败反馈、进程重启读取均包含快照。
- 覆盖范围见 `asset_snapshot_test.dart`、`personal_finance_ui_test.dart`、`unified_expense_account_test.dart`、repository contract 与 migration matrix。

## 当前边界

快照需要用户主动核对保存，不自动补齐历史月份，也不联网获取基金净值或自动换算外币估值。首次建立历史快照时，流水推导值只是录入起点，应按当时银行账单或基金市值核对。
