# 分类预算与资产录入改进开发说明

日期：2026-11-05。基于已发布 `v1.20.16`（`fd6a8a8`）的手机反馈与源码排查。

本文汇总下一轮修改建议、数据边界与验收标准，尚未实现。目标设备为小米 14。本轮优先处理动画、预算入口和资产录入；无感自动记账单独见 [接入设计](huayoupu-auto-accounting.md)，不与这批修改混合。

## 动画修改

### 排查结论

`VeriSegmentedControl` 使用 `AnimatedToggleSwitch<T>.rolling`，依赖包内部按移动距离计算旋转角，对前景文字执行 `Transform.rotate`。看板及其他复用位置会受影响，这是当前组件模式造成的表现。

固定底部导航使用独立的 `VeriBottomBar`，图标最多摆动约18°；根页面经 `PageView` 和弹簧模拟横向滑动，另有可选液态玻璃样式。源码不足以证明底部主页面会旋转360°，不能把分段按钮的原因直接套用于根导航。真机需记录当前导航样式，分别核对点击、手势、跨多个标签和连续改目标的表现。

### 目标交互

- 分段按钮文字保持正向和固定槽位，选中背景短暂平移，不旋转或翻面。
- 根导航建议取消图标摆动和扫线，以颜色、选中态反馈；页面采用短暂平稳的横向滑动。
- 连续点击响应最后一次选择，中间页面不抢回选中态；手势翻页与底栏保持同步。
- 保留导航样式设置、页面存活、滚动位置和无障碍语义；尊重系统减少动画设置。

主要源码：`lib/app/common_widgets_forms.dart`、`lib/app/veri_bottom_bar.dart`、`lib/app/root_navigation_docked.dart`、`lib/app/root_navigation_liquid_glass.dart`、`lib/pages/shell.dart`。

## 分类预算交互

| 区域 | 修改后的行为 |
| --- | --- |
| 首页分类预算行 | 直接编辑该分类当前预算键月额度 |
| 首页预算标题或查看全部 | 进入对应月份预算总览 |
| 预算总览分类行 | 直接编辑该分类、当前所选月份或周期的额度 |
| 默认预算设置页分类行 | 直接编辑默认额度，标题说明每期沿用 |
| 分类行左侧三点 | 仅显示该行操作菜单；按用户要求放在左侧 |
| 父分类展开箭头 | 仅展开或收起子分类，不打开菜单或金额输入 |

总览和设置页当前将 `onTap`、`onActions` 都绑定到 `openMenu`，需要分开绑定。沿用统一数字键盘作为金额编辑子界面，不额外创建一套金额输入。编辑标题同时说明分类与月份/周期，取消不写入。三点和展开箭头应有独立点击区域，避免事件串到整行。

自然月显示「本月」或具体月份，自定义预算周期显示「本期」或日期范围。历史月份操作必须写入所选预算键月，不能回落到今天所在月份。默认预算设置与单期预算编辑保持分开。

主要源码：`lib/pages/home_category_budget_panel.dart`、`lib/pages/budget_pages.dart`、`lib/pages/budget_settings_page.dart`、`lib/pages/budget_widgets.dart`。

## 预算恢复默认与本期停用

当前「清空预算」实际删除单期覆盖，再回落默认额度；`setCategoryBudget(..., 0)` 同样如此。默认1000、本期1500时，清空后是1000，不是0。

建议明确区分三种状态：

| 状态 | 数据建议 | 默认1000时的结果 |
| --- | --- | --- |
| 沿用默认 | 单期键不存在 | 有效额度1000 |
| 单期金额 | 单期键保存正数 | 本期1500，其他期1000 |
| 本期停用 | 单期键保存显式0 | 本期无额度，其他期1000 |

菜单建议采用「设置本月预算／设置本期预算」「恢复默认预算」「本月不设预算／本期不设预算」。默认预算设置页使用「设置默认预算」「删除默认预算」，不复用「清空预算」。停用额度不删除消费，也不把消费改成“不计入预算”。

显式0是新的语义，需要调整 API 与所有调用点，不能仅改文案。旧数据缺少单期键仍解释为沿用默认，不虚构过去停用状态。核对 SQLite、备份恢复和数据归一化是否保留显式0；默认预算0继续表示未设置。首页不能因为 `hasBudget == false` 隐藏本期停用分类，应保留状态及重新启用入口。父子额度不重复求和，支出沿用现有预算计算口径。

主要源码：`lib/app/veri_fin_controller_ops.dart`、预算模型与仓储；现行规则见 [分类默认预算与单期覆盖](category-budget-override.md)。功能实施时同步现行文档，不提前将建议描述为已实现。

## 资产组织与首次建档

采用「银行卡或平台为分组，可独立核对余额的资产为账户，活期/定期/基金等为资产类别」。分组不另存一份余额，不能同时将整张卡总额与卡内子账户金额计入总资产。

| 银行卡分组 | 账户示例 | 资产类别 | 填写金额 |
| --- | --- | --- | --- |
| 招行尾号1234 | 招行日常活期 | 活期存款 | 当前余额 |
| 招行尾号1234 | 招行一年定期 | 定期存款 | 核对余额，不自动预计未到账利息 |
| 招行尾号1234 | 招行债券基金 | 债券基金 | 当时市值，不是累计投入本金 |
| 工行尾号5678 | 工行股票基金 | 股票类基金 | 当时市值 |
| 工行尾号5678 | 工行美元定期 | 外币定期 | 原币余额与手填人民币估值 |
| 工行尾号5678 | 工行美元活期 | 外币活期 | 原币余额与手填人民币估值 |

不同到期日的定期、需要独立跟踪的基金可继续拆分。账户类型只控制银行卡号、信用额度等能力，不替代资产类别。已有账户应能修改类别与分组，不要求删掉重建。

资产页提供清晰的「添加资产」入口，表单突出资产类别、所属银行卡、名称、币种、余额；银行卡选择器内支持新建分组，减少往返。月度资产空状态提供添加资产操作，已有账户时提供「添加账户到本月」或明确的管理入口。

首次流程应能连续完成：建立银行卡 → 添加该卡各类资产 → 指定日常扣款活期 → 核对本月 → 保存。统一支出仍只扣指定活期；活期转入定期或基金记录为转账。首次填写初始余额，后续修改当前余额走已有余额调整规则，不伪造生活收支。

主要源码：`lib/pages/assets_pages.dart`、`lib/pages/add_account_page.dart`、`lib/pages/account_group_pages.dart`、`lib/pages/account_detail_page.dart`。现行模型见 [月度资产与统一支出账户](monthly-assets.md)。

## 月度快照与当前余额

### 补入遗漏账户

编辑已有快照当前只沿用旧账户模板，缺少添加入口。建议保留原快照金额，增加显式补入操作，按账户ID去重；原有账户的金额、估值、名称和分组不因刷新自动覆盖。

历史月份不自动纳入今天新建的账户，也不将今天余额当成历史真实值。用户补录历史账户时填写该月实际金额，缺少资料时保留未核对状态。已关闭、隐藏或删除账户的历史快照继续保留，不能根据当前账户列表删除过去记录。

### 余额职责

- 当前账户余额用于日常扣款、转账和实时展示。
- 月度快照记录该月核对结果，保存历史快照不能修改今天余额或流水。
- 核对页明确「仅保存本月对照记录」，账户详情明确当前余额和调整入口，避免两个时点都只标为“余额”。
- 不默认将快照回写当前账户；如需同步，通过独立的当前余额调整操作复用既有规则，避免重复扣款。

### 外币手填人民币估值

建议当前外币资产增加独立人民币估值和估值时间，首页汇总使用手填值；月度快照保存当月独立估值，历史冻结。当前估值不能反向覆盖历史，历史估值也不能自动冒充今天估值。保留原币余额，不要求用户输入汇率，不联网自动换算。

未填估值时显示未估值，不按0伪装成完整总资产。原币余额变化时提示估值需重新核对；首页总额、分组小计和图表使用一致口径。历史趋势缺少数据就显示缺失，不用今天估值补历史。现有交易的冻结金额和汇率保持原义，资产估值不改写已记流水。

此项涉及当前估值模型、SQLite、备份和图表，不能只把首页数字替换为最近一次快照总额。

主要源码：`lib/pages/asset_monthly_page.dart`、`lib/app/veri_fin_controller_assets.dart`、`lib/app/asset_snapshot_math.dart`、`lib/app/models/account.dart`、`lib/data/app_database.dart`、`lib/data/ledger_repository.dart`。

## 验收与交付

| 范围 | 必须核对的结果 |
| --- | --- |
| 动画 | 看板、资产维度和卡片内切换文字不旋转；底栏连续点击、跨页与手势后位置一致 |
| 预算入口 | 整行直接编辑，三点才开菜单，箭头只展开；首页带入正确分类与预算期 |
| 预算状态 | 默认1000 → 本期1500 → 恢复1000 → 本期停用 → 再恢复1000；重启与备份恢复后不变 |
| 预算隔离 | 本期不影响默认或其他月份；历史期写正确键月；不同账本不串数据 |
| 资产建档 | 至少两张卡、每卡多类别可录入、分组和编辑；基金填市值；支出只扣指定活期 |
| 快照补录 | 已保存月份可加遗漏账户，旧金额不变；新账户不自动污染历史；历史账户不丢 |
| 余额边界 | 改历史快照不改今天余额；改当前余额不改冻结月份；不重复生成收支或扣款 |
| 外币 | 原币与人民币分别录入、时间明确；缺估值不当成0；首页与月度口径可解释 |

本轮仅写文档，不触发功能测试。后续以变更相关的定向测试、小米14真机操作及必要的迁移/备份检查为主。动画需观察中间帧，不能只检查 `pumpAndSettle` 后的最终状态；涉及 schema 变更须补迁移与恢复验证。发版沿用现有 CI 门禁，避免在本机与 CI 重复执行全量测试。

功能实施时同步中英文文案、领域文档、组件约定及 `CHANGELOG.md`，以实际完成范围为准。该说明不代表所有建议均已确定实现，不改动已发布版本标签。
